## 更新内容

- 完善 URL 与 Params 的双向同步，处理重复参数、编码、禁用项及旧数据兼容。
- 改进目录、接口和请求用例搜索，保持搜索前的目录展开状态。
- 增加统一创建菜单及空工作区的“新建接口”入口。
- 统一弹窗、下拉框、响应头列表、焦点和按钮样式。
- 修复缩小窗口后“保存”按钮图标和文字消失的问题，避免最小化时执行无效布局。
- 加固请求进行中关闭标签的线程收尾，关闭后仍可重新打开接口并继续发送请求。
- 新增一键真实场景测试：公网 HTTP、正式 EXE 核心操作、真实磁盘持久化及窗口样式截图。测试数据独立存放，并增加提前退出检测、截图超时和 TCP 连接检查。
