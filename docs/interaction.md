# 日常调试交互

## 编辑与保存

- 参数表支持单击编辑，Tab / Shift+Tab 在名称、值、类型和说明之间移动，跨行连续录入。首尾边界会离开表格，不会无限新增空白行。
- Enter 提交单元格，Esc 撤销本次单元格编辑；表格内 F2 编辑，左右方向键选择列，Delete 删除行，空格切换启用状态。
- 标签上的圆点表示未保存修改。工具栏显示当前保存状态；“保存全部”及 Ctrl+S 保存全部接口、用例和目录修改。
- 编辑已有用例后保存，会更新该用例的请求和当前响应，保留其身份及所属接口。取消或网络失败不会覆盖上次响应。
- 关闭有修改的标签时可保存全部、放弃目标标签修改或取消。批量关闭只询问一次。放弃未保存的新建接口会一并移除它的用例。
- 保存失败会保留编辑内容和未保存状态，并阻止本次关闭或退出。目录展开、切换标签、发送请求不会自动保存。

## 快捷键与响应

| 操作 | 快捷键 |
| --- | --- |
| 聚焦并选中 URL | Ctrl+L |
| 发送请求 | Ctrl+Enter |
| 保存全部 | Ctrl+S |
| 关闭当前标签 | Ctrl+W |
| 下一个 / 上一个标签 | Ctrl+Tab / Ctrl+Shift+Tab |
| 复制当前接口 | Ctrl+D |
| 查找响应 | Ctrl+F |
| 查找下一个 / 上一个 | 查找框内 Enter / Shift+Enter |
| 关闭查找 | 查找区或响应正文内 Esc |

发送前校验 URL 和 JSON。请求中显示耗时，取消后显示“正在取消”和“已取消”。等待、取消或网络失败时，保留的正文标为“上次响应”。HTTP 4xx/5xx 的正文可以正常阅读。

响应区可切换格式化或原始文本，并支持查找；选中文字后可用 Ctrl+C 复制。Body / Headers 使用无外框的轻量标签，以文字下方的蓝色细线标识选中项。显示方式以代码花括号图标下拉固定在标签右侧，用细分隔线分组，悬停提示当前模式；查找使用工具栏右侧的放大镜图标。两个图标按钮悬停时显示浅灰底色，保留键盘焦点与文字提示。Ctrl+F 或查找图标展开查找框时，显示方式与正文位置保持不变。选中正文中的单行文字后按 Ctrl+F 会带入选中文字；输入即定位第一个匹配，Enter / Shift+Enter 切换下一个 / 上一个，Esc 关闭后继续阅读正文。查找框内集中显示匹配位置、数量及导航按钮，无匹配或内容为空时禁用导航。

可见匹配使用浅色底纹，当前匹配加深，保留 JSON 原有语法颜色。大响应只对可见范围及当前匹配绘制高亮，滚动时更新；匹配总数和前后导航仍覆盖全文。输入查找词或切换匹配时，正文会自动纵向、横向滚动到当前结果，键盘焦点留在查找框或导航按钮；匹配词超出可视宽度时优先显示开头。关闭查找会清除底纹并保留当前选区、滚动位置。每个标签分别保留视图模式、查找词、匹配位置、选区及滚动位置。

格式化 JSON 使用不同颜色区分字段名、字符串、数字及布尔值/null，字段名加粗；正文增加内边距和行距。双击英文单词或字段名可选中连续的英文字母、数字和下划线，不包含两侧引号或标点。原始模式使用统一文字颜色。为避免大响应卡顿，超过 512K 字符的正文保留缩进而不着色，单次最多着色 20,000 个词法片段。

## 开发验证

现有 `FeatherApiSelfTests` 覆盖存储、JSON、导入和本地 HTTP 回归。新增 `FeatherApiUiTests` 直接验证真实窗口控制器，替换数据加载、保存及关闭对话框选择，不访问用户数据。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -Action Test
```

模块划分与开发入口见 [开发架构](architecture.md)。增加了 `FeatherArchitecture` 依赖边界检查。

也可以使用 Visual Studio 分别构建 `FeatherApi.vcxproj`、`FeatherApiSelfTests.vcxproj`、`FeatherApiUiTests.vcxproj`。

- `FeatherApiUiTests.exe --test`：自动运行保存、关闭、参数导航、响应状态和 100% / 150% / 200% 布局计算回归。
- `FeatherApiUiTests.exe`：打开隔离数据的交互验证窗口，测试数据位于该可执行文件旁的 `ui-sandbox/data.json`。用于人工检查鼠标、输入法、键盘焦点与实际显示缩放。

数据文件格式保持不变，不需要迁移。自动布局检查不能代替真实显示器下的视觉检查。

查找重绘需在可见窗口中检查：打开多屏长度的 HTML 响应，查找重复词，使用 Shift+Enter 从首个匹配循环到末尾，再按 Enter 返回首个匹配，并手动滚动正文。确认文字与滚动位置一致，没有旧行残留、叠字，且可见匹配的底纹正常更新；隐藏窗口中的选区与格式检查无法覆盖屏幕像素残留。
